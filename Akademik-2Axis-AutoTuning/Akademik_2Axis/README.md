# Akademik Tryoshnikov 2-Axis Stabilization Simulator

## 주요 기능
- 가상 파도 시험 모드
- Akademik Tryoshnikov ACE INS 전체 일별 기록 자동 다운로드
- 모든 일별 파일/연속 구간의 시간순 자동 재생 및 다음 구간 자동 이동
- 파랑 재구성 자료 자동 다운로드 및 Hs/Tp 최근접 시간 매칭
- FF, Kp, Kd, 상보필터 α 자동 후보 탐색
- 날짜 단위 학습/검증 구간 분리, 성능 비교, 최적값 적용, 후보 CSV 저장

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 실제 항해 데이터
앱에서 `Akademik 전체 항해 데이터` 모드를 선택한 다음 `전체 항해 데이터 자동 다운로드 및 등록`을 한 번 누릅니다.
- ACE INS ZIP은 약 646.9 MB이며, 앱은 다운로드한 ZIP을 캐시에 보관하고 날짜별 CSV를 압축 해제하지 않고 순차적으로 읽습니다.
- 파고/주기 CSV도 자동으로 내려받습니다.
- 날짜별 파일을 하나씩 업로드할 필요가 없습니다. 현재 구간 종료 시 다음 연속 구간으로 자동 이동합니다.
- 데이터 캐시는 사용자 홈 폴더의 `.cache/akademik_2axis`에 저장됩니다. GitHub에는 대용량 데이터가 올라가지 않습니다.

## 자동 최적화
- 조정 대상: FF, Kp, Kd, 상보필터 계수 α
- 고정 대상: 서보 τ/최대 각속도/회전 한계, 가상 센서 노이즈·바이어스 설정
- 모든 날짜 파일에서 대표적인 4분 창을 추출해 탐색하고, 일부 날짜는 검증용으로 따로 둡니다.
- 원본 INS가 1 Hz이므로 자동 최적화는 1 Hz 원자료 구간에서 수행합니다. 재생 화면은 50 Hz 제어 모델에 맞춰 선형 보간하지만, 보간은 원본에 없는 고주파 움직임을 복원하지 않습니다.
- 자동 최적화 결과는 현재 수학적 모델에 대한 추천값입니다. 실물 제품에 적용하기 전 실제 50 Hz IMU와 서보를 연결해 낮은 이득부터 검증해야 합니다.

## 데이터 출처 / 라이선스
- Thomas & Pina Estany (2020), ACE INS, Zenodo DOI: `10.5281/zenodo.3733228`, CC BY 4.0.
- Derkani et al. (2021), ACE reconstructed sea state, Zenodo DOI: `10.5281/zenodo.4541564`, CC BY 4.0.
- INS 원자료는 제공기관 설명상 보정 및 품질검사를 거치지 않았습니다.
- Hs/Tp는 선박 Heave 5분 기록과 선박별 RAO를 이용한 재구성 자료이며, 독립 부표의 직접 측정값과 구분해야 합니다.
