Akademik 전체 항해 데이터 자동 재생 + 제어 자동 최적화 버전

[기존 GitHub 프로젝트 업데이트]
1. ZIP을 다운로드하고 압축을 풉니다.
2. 안의 Akademik_2Axis 폴더에 app.py, requirements.txt, README.md, .gitignore가 들어 있습니다.
3. 기존 컴퓨터의 Akademik_2Axis 폴더에서 app.py와 requirements.txt를 새 파일로 교체합니다.
4. GitHub 저장소의 Akademik_2Axis 폴더에도 같은 파일을 업로드/교체하고 Commit changes를 누릅니다.
5. Streamlit Community Cloud는 GitHub 변경 사항을 감지해 다시 배포합니다.
6. 배포 설정의 Main file path는 Akademik_2Axis/app.py로 유지합니다.

[실제 항해 데이터 사용]
1. 앱 왼쪽 운용 모드에서 'Akademik 전체 항해 데이터'를 선택합니다.
2. '전체 항해 데이터 자동 다운로드 및 등록'을 한 번 누릅니다.
3. INS 전체 ZIP(약 646.9MB)과 파랑 Hs/Tp CSV를 앱이 자동으로 다운로드합니다.
4. 최초 다운로드 후 날짜별 일일 CSV를 하나씩 업로드할 필요가 없습니다.
5. '구간 종료 시 다음 항해 기록 자동 재생'이 켜져 있으면 다음 일별 파일/연속 구간으로 넘어갑니다.

[자동 최적화]
1. 전체 데이터 다운로드/등록을 완료합니다.
2. 화면 아래 '전체 항해 데이터로 자동 최적값 찾기'를 누릅니다.
3. 프로그램이 모든 일별 파일의 대표 구간으로 FF, Kp, Kd, α 후보를 비교합니다.
4. 학습에 쓰지 않은 일부 날짜의 검증 결과도 표시합니다.
5. '추천 파라미터를 제어 슬라이더에 적용'을 누르면 사이드바 값이 바뀝니다.
6. 후보표를 CSV로 저장할 수 있습니다.

[중요]
- GitHub에 646.9MB 원본 ZIP을 업로드하지 않습니다. 앱이 Zenodo에서 자동으로 내려받습니다.
- 로컬/클라우드 실행 환경의 캐시에 다운로드 파일을 저장합니다. 앱 환경이 초기화되면 다시 다운로드해야 할 수 있습니다.
- INS 원본은 1Hz입니다. 50Hz 보간은 시각화와 제어 모델 입력을 위한 계산이며, 실제 고주파 운동을 복원하지 않습니다.
- 자동 최적값은 현재 시뮬레이터와 가정된 센서/서보 조건에서의 후보값입니다. 실제 장치 적용 전 반드시 실제 IMU와 서보 측정값으로 검증해야 합니다.

[로컬 실행]
Anaconda Prompt에서 Akademik_2Axis 폴더로 이동한 다음:
  pip install -r requirements.txt
  streamlit run app.py
